Hihi! This is a base for making your own PupBase Pup! It includes 20 slots so be sure to delete the ones you don't use.
To edit this you should have some version of Visual Studio.



Make sure to change everything in ModFiles like the thumbnail and ModInfo so it's not a placeholder.

^ Change above info in Plugin.cs too or else it won't work.

From there you can edit the pups data and whatnot how you wish. The guide for all of this is here: https://github.com/kleiner-sentry/PupBase/wiki

Once you are finished, Replace the file in ModFiles\Plugins\Replace with the new DLL you just built.

From there everything should be good!
